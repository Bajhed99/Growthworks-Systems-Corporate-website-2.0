## Explicitly Excluded Package Behaviors

The supplied ZIPs were inspected without executing their package scripts. The implementation excludes unsupported or conflicting material: external tool providers, canvas spotlights, interactive center capability states, autoplay/looping motion, horizontal swipe galleries, fake recommendation examples, ratings, review claims, third-party brand placeholders, unapproved legacy terminology, gold-led palette, and product-interface copy. These exclusions preserve the supplied packages’ structural role without violating the governing homepage documents or fabricating trust signals.

## Asset Use Verification Rule

After implementation, the homepage must not reference `gws-editorial-reference`, `ai-buyer-journey`, `gws-revenue-infrastructure`, `gws-system-application`, or `gws-mark` generated assets. The code must instead contain the adapted live components derived from the named supplied package structures.
