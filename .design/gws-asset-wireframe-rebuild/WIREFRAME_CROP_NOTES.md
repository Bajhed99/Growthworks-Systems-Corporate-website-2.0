## Package Review Boundaries

The **Buyer Journey** package contains unsupported content and styling that cannot be transferred verbatim: generated business examples, third-party review/rating signals, animation, gold-heavy color, and product-like interactive behavior. The rebuild will preserve only the supplied package’s approved wireframe structure and static discovery contrast, using the governing homepage language and approved GWS palette. No ratings, review claims, unnamed third-party examples, or simulated recommendation result will be rendered.

The **Fragmented vs Connected** package is an exploratory interactive comparison, not the approved homepage section. Its swipe behavior, dense cards, horizontal overflow, gold palette, generic system terms, and selection-driven capability details conflict with the final mobile ruling and will be excluded. Its safe contribution is limited to the visual distinction between disconnected and connected operation, which the supplied desktop/mobile wireframes already reduce into the approved three-stage Revenue Infrastructure composition.

The **Revenue Infrastructure** package supplies the correct underlying three-stage structure: a disconnected-tools rail, a compact Revenue Infrastructure center, and a business-outcomes rail. It also contains an explicit mobile vertical connector and one-open behavior for outer groups. The rebuild will incorporate that structure while replacing `AEO / Search` with the current canonical **Search & AI Visibility**, preserving the source-copy authority, removing the unsupported Figma provider and canvas spotlight, avoiding animated connector beams, and keeping the center capability state permanently static as required by the final mobile ruling.
