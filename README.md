# GWS Website 2.0

A modern, responsive website redesign for Global Wealth Solutions showcasing AI-powered capabilities and business value propositions.

## Quick Start

### Prerequisites
- Node.js 18+ and npm
- Git

### Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit `http://localhost:3000` to see the site.
